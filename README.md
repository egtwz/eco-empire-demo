# 🌿 EcoEmpire Demo

Мини-демо Telegram Mini App на React + TypeScript + Vite.

Функционал: поле 5×5, посадка семян, таймер роста (10 сек), сбор плодов, магазин, инвентарь, скупщик, баланс $ECO, сохранение прогресса в localStorage, базовая анимация модалок (Framer Motion), инициализация Telegram WebApp, заглушка TonConnect.

## Запуск

```bash
npm i
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Деплой

Готово к деплою на Vercel/Netlify. Для Telegram Mini App укажите URL билда и включите WebApp.

## Стек

- React + TypeScript + Vite
- TailwindCSS
- Framer Motion
- Telegram WebApp SDK
- TonConnect UI (заглушка)
